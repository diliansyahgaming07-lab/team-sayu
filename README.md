# Team Sayu - Clustering Data Stunting

## Deskripsi Proyek

Proyek ini merupakan implementasi Machine Learning menggunakan metode **Clustering** untuk mengelompokkan data prevalensi stunting di Indonesia.

Metode yang digunakan adalah **K-Means Clustering**, yaitu algoritma Unsupervised Learning yang bertujuan untuk mengelompokkan data berdasarkan kemiripan karakteristiknya.

Melalui proyek ini, dilakukan pengelompokan provinsi berdasarkan tingkat prevalensi stunting untuk mengetahui pola dan karakteristik setiap kelompok.

## Tujuan

- Memahami penerapan algoritma K-Means Clustering.
- Mengelompokkan data prevalensi stunting berdasarkan kemiripan.
- Mengetahui pola persebaran tingkat stunting di Indonesia.
- Memvisualisasikan hasil clustering dalam bentuk tabel dan diagram.

## Teknologi yang Digunakan

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Metode

Metode yang digunakan dalam proyek ini adalah K-Means Clustering dengan tahapan:

1. Memuat dataset stunting.
2. Melakukan eksplorasi dan preprocessing data.
3. Menentukan jumlah cluster.
4. Melakukan proses clustering menggunakan K-Means.
5. Menganalisis hasil pengelompokan.
6. Menampilkan visualisasi hasil clustering.

## Dataset

Dataset yang digunakan berisi data prevalensi stunting di Indonesia berdasarkan provinsi dan tahun.

Data digunakan untuk melihat kemiripan tingkat prevalensi stunting antarprovinsi.
